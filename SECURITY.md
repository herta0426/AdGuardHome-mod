# Security policy

This repository is an **unofficial mod** of AdGuard Home, maintained by its
owner.  There is no security team and no response SLA behind it.

## Reporting an issue in this mod

- For a vulnerability that could be exploited (remote code execution, XSS,
  DNS rebinding, and so on), use the private reporting form: the
  **Security** tab of this repository → **Report a vulnerability**.
- If that form is unavailable, open a regular issue without the details and
  ask for a private channel.
- For everything else, a regular [issue][issues] is fine.

[issues]: https://github.com/herta0426/AdguardHome-Mod/issues

## Reporting a vulnerability in AdGuard Home itself

This mod tracks AdGuard Home, so most of the security work happens upstream.
Report issues that also affect the upstream project to AdGuard Software Ltd.
at <security@adguard.com>, as described in the upstream security policy:

- <https://github.com/AdguardTeam/AdGuardHome/blob/master/SECURITY.md>

## 中文说明

本仓库是 AdGuard Home 的非官方 Mod，没有专职安全团队。

- 本 Mod 的可利用漏洞：请通过本仓库 **Security** 页的 **Report a

  希望私下沟通。
- 同样影响上游 AdGuard Home 的漏洞：请按上游流程报告到
  <security@adguard.com>。
